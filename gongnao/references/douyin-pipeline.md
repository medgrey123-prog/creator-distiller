# 抖音接入说明（可选能力，不是捆绑抓取器）

通用核心不依赖抖音。现有平台工具获取资料后，转换为 [本地数据约定](local-workflow.md) 即可处理。

## 采集合同

1. 确认主页和账号身份，不凭同名认人；记录主页 URL、账号标识、采集时间、请求的时间/数量范围。
2. 使用用户当前有权使用的 API、导出工具或浏览器能力。需要登录时由宿主支持的授权方式处理。此包不扫描浏览器配置、不导出 Cookie、不移除登录或访问限制。
3. 记录分页、错误、终止原因、重复 ID 和过滤条件。某次响应的 `has_more=0` 必须属于目标账号的正确列表，也只支持“本次可见范围已到末页”。无完整证据标记 partial/unknown。
4. “最新 N 条”不能仅按首次捕获顺序判断，置顶和分页会影响顺序；在足够范围中按发布时间排序，并说明可见性限制。
5. 视频、图文、长文分别处理。音视频转录记录引擎、语言、时间戳与校对状态；文字正文无需伪装成转录；无法取得正文的条目也留在清单中。
6. 抓取器、下载器、ASR 的依赖、费用、系统支持与权限由实际所选工具说明。本包未提供这些引擎，不宣称在任意系统自动抓取成功。

## 已有归档迁移

若已有 `awemes_full.json`，可把每个 `aweme_id` 转为 `dy_<原ID>`，公开作品链接填 `url`；描述填 `title`，发布时间转 ISO 8601，视频时长由毫秒转秒。正文/转录复制到归档内部的 `raw/` 后，用相对路径填 `text_path`。不要把视频签名 URL、完整响应、会话字段直接复制进新清单。

类型须根据实际内容判断，不能只用 duration 是否为零区分视频与长文。迁移后的来源数和原清单唯一 ID 数应一致；缺失正文标记 missing，未确认的范围标记 unknown。文件较多时由 Agent 使用当前环境编写一次性转换，先在副本验证，不改原归档。

本包不附带平台抓取、下载或转录程序。需要自动抓取时，应作为独立适配器实现，并以真实账号权限和当前环境验收；历史案例不能作为当前通过的证据。
