# 领域与证据边界

共脑用于理解任何人的知识与思想，不默认认可其结论。按材料选择必要检查，不能机械地给每个行业套同一套业务指标。

| 领域 | 整理时保留什么 | 当用户要求现实应用或核实时 |
|---|---|---|
| 法律 | 国家/地区、适用时间、规范层级、案例事实、裁判与讲述者解释的区别 | 核对现行规范及适用条件；一般讲解不是特定案件的法律结论，缺关键案情时不补造 |
| 医学与健康 | 人群、适应证、研究类型、证据等级、限制、相关性与因果的区别 | 核对现行权威指南或原始研究；科普与个人经历不能直接推成个人诊断、处方或用药调整 |
| 科学与工程 | 定义、假设、单位、实验/计算条件、版本、误差及可复现性 | 依据任务检查推导、数据和适用条件；不把离开原条件的外推当已证实 |
| 教育与心理 | 年龄、人群、场景、研究设计和个体差异 | 区分研究结果、教学经验与建议；不凭个案保证普遍效果 |
| 财经与商业 | 时间、市场、样本、成本、风险与利益关系 | 核对当前数据；历史叙述不构成未来收益保证，也不自动成为个性化建议 |
| 哲学、人文与社会议题 | 术语定义、前提、价值立场、解释传统和反对意见 | 区分经验事实与规范主张；不能把观点分歧一律化约为事实错误或强行调和 |
| 日常经验及其他领域 | 个人处境、观察范围、故事与一般判断的区别 | 按主张性质确定可核验项，不因没有专业头衔而否定材料，也不因真诚而认定普适 |

这些是分析条件，不是上述领域的实体结论。说明“某人主张 X”只证明观点归属；说明“X 当前成立”需要额外依据。高风险专业应用保留必要的专业审核边界，仍继续完成不依赖该决定的知识整理。

可给来源或卡片补充：领域、发言人、材料日期、适用地区/人群/系统、主张类型、证据类型、外部核实状态。信息未知就标未知，不推断补齐。法律/医学等材料即使观点正确，过时、不同辖区或不同人群也可能不适用。
