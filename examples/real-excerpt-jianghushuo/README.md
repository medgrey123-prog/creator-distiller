## 核验状态

保留的卡片来自历史产出；本目录没有随附完整原文、转录和统计计算过程，本次发布未重新核验其来源归属、覆盖数量、比例或效果。裸作品 ID 只能提供检索线索，不能替代原文定位。这里展示字段细度，不作为当前版本的正确性样板；实际使用应重新核对原文并按现行引用规则补证。

## 值得看的地方

- **卡片字段是完整的**：定义、要解决的问题、思维逻辑、适用场景、边界与反例、落地入口、来源；并区分“原作者观点”和“原作者观点 + 归纳”。
- **冲突不合并**：例如“做简单的事”和“做难的事”并列保留，历史文件给出的条件解释属于待核实归纳，不能视为冲突已解决。
- **自述数字单独标口径**：方法卡里凡是作者自述的数据都标“作者口径”，没有写成事实。
- **表达型不照搬原话**：先列出口头禅、独有案例、独有比喻作为“禁止复现清单”，再用抽象结构写出新范文。
