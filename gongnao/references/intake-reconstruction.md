# 从理解到应用：补充必要信息

仅在用户需要现实应用且材料不够时补充信息；纯知识学习不要求先填业务问卷。以下重建结果标为分析者推导，不冒称原讲述者的方法。

1. **概念倒推**：要理解或使用某个概念，需要哪些定义、前提和背景？例如，一项判断是否依赖特定人群、制度、环境或技术版本。
2. **决定倒推**：先明确用户真正要作出的决定，再找必须输入。学术理解可能需要术语与理论背景，工程选择需要条件与约束，专业应用需要对应领域事实；不预设产品、流量或变现目标。
3. **实录核对**：从合法可用的访谈、答疑、讨论中提取原讲述者真实问过的问题及追问条件，保留出处；与分析者重建的问题分开。
4. **实际反馈**：信息充分就推进；应用后记录结果、偏差、反例与尚不明确的条件。没有实际数据就不宣称验证有效，不规定固定轮次或跨行业统一指标。

记录格式可用：用户问题 / 所需输入 / 已知事实 / 缺口 / 来源 / 对结论的影响。不能把所有“不落地”都归因为缺信息，也要检查框架是否适用、证据是否不足。
