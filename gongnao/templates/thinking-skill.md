# 思考型 Skill 生成要求

这是编写成品的要求，不应原样作为成品入口。依据已选人物底库填写具体框架、知识路径和场景，不保留占位符。

## 入口需要教会 Agent 的行为

1. 理解用户的新问题、目标、已知事实和约束，只补问会改变判断的信息。
2. 根据问题读取 `knowledge/index.md`，选择实际适配的概念/判断方法，读取完整卡片及反例。说明选用理由，不强迫所有问题进入作者框架。
3. 将用户事实映射到概念的前提、变量和条件，区分已知、缺失和假设；再展开推理链。证据不支持时降低结论强度或明确不适配。
4. 提供推导过程、替代解释/路线、条件变化会如何影响判断；材料有行动方法且任务需要时再生成具体动作。
5. 关键结论关联 C/M 编号、来源与本次用户事实。作者没有提出的迁移、步骤和指标标记为新推导。
6. 输出服务当前任务，不要求每次复述整个知识体系；收到新事实或反例后重新判断。

## 输出与验收

根据任务给出结论、推理依据、适用范围和下一步；纯理论讨论可以交付分析而不硬凑行动清单。知识库包含概念与方法的完整条件、案例与反证，入口按需读取。

试运行优先选用户真实的新问题，观察是否进行了跨情境的合理映射、是否识别不满足的前提、是否把推导冒充作者原话。只重复作者说过什么不算实现思考能力。
