# 示例：三条材料怎样变成三件套

本页所有原始材料都是为项目新写的虚构文本。下面是**人工编写的产物示意**，用于展示证据关系，不是模型实测成绩，也不是所有任务必须套用的答案。

## 输入是什么

| 来源 | 原文要点 | 可以支持什么 |
|---|---|---|
| [sample_001](mini-archive/raw/sample_001.txt) | 探索新方向时先用现有设备少量尝试，记录受众问题；一次高播放不证明稳定 | 探索阶段先观察反馈的建议 |
| [sample_002](mini-archive/raw/sample_002.txt) | 多次尝试带来实际询问、团队能稳定交付时，可以增加制作投入 | 扩大投入的两个前置条件 |
| [sample_003](mini-archive/raw/sample_003.txt) | 任何情况下都应发布前买齐设备；没有最好设备不可能成功 | 一条与前文冲突的绝对判断，未给验证数据 |

范围是这 3 条测试材料，不代表任何真实人物的全部作品。文件首行是虚构素材标记，下文“正文第 1 段”指该标记之后的内容。

## 先做逐条总结

以 `sample_002` 为例：

> **核心观点：** 有较稳定需求信号且具备稳定交付能力后，可考虑增加制作投入。
>
> **内容详解：** 材料给出两项条件：多次尝试带来目标受众的实际询问；团队能够稳定交付。作者明确区分这一阶段与刚开始探索。
>
> **方法信息：** 先检查需求与交付，再决定是否增加投入；没有给出次数、金额或效果阈值。
>
> **表达观察：** 用“如果……而且……可以……”表达条件，再用“不是刚开始探索”限定范围。
>
> **来源与疑点：** `[source:sample_002]` 正文第 1 段。何谓“稳定”、应增加多少投入尚未说明。该建议的实际效果未验证。

使用脚本生成正式总结时，还需复制对应 bundle 顶部的输入指纹。本页为阅读示意，未伪造运行时指纹。

## 产物一：概念体系

### C1：投入随证据调整

- **性质：** 分析者给出的归纳名称，原文未命名这个概念。
- **一句话定义：** 将投入决策与所处阶段、需求反馈和交付能力联系起来。
- **解决的问题：** 如何判断继续探索还是增加投入。
- **判断逻辑：** 第一条讨论探索期的小规模尝试，第二条讨论已有需求反馈后的扩大条件。
- **适用条件：** 只能说这两条材料支持这一整理方式，不能将其推广成所有行业的规律。
- **边界与反例：** 第三条无条件主张先买齐设备，与前两条存在冲突；材料不足以解释。
- **方法入口：** M1，小规模验证后再评估投入。
- **来源：** `[source:sample_001]`、`[source:sample_002]` 正文第 1 段；冲突来源 `[source:sample_003]` 正文第 1 段。

## 产物二：方法论地图

### M1：小规模验证后再评估投入

| 字段 | 示例内容 |
|---|---|
| 目标 | 为是否增加制作投入提供更明确的依据 |
| 对应概念 | C1，投入随证据调整 |
| 输入 | 待尝试方向、现有设备、目标受众的反馈、团队交付情况 |
| 步骤 | 用现有设备少量尝试 → 记录受众问题 → 检查是否反复出现实际询问 → 检查交付是否稳定 → 决定继续观察或增加投入 |
| 输出 | 一份投入判断，列明采用的信号与仍缺的信息 |
| 建议验收 | 能说明需求信号和交付条件，而不是只凭一次播放量判断；这是分析者提出的检查方式，未验证效果 |
| 失败信号 | 缺乏需求反馈、无法稳定交付，或把偶然高播放当稳定信号 |
| 尚缺参数 | 尝试多少次、观察多久、增加多少预算；原文未提供，不代填数字 |
| 来源 | `[source:sample_001]` 与 `[source:sample_002]` 正文第 1 段 |

**冲突处理：** `[source:sample_003]` 仍列入待验证清单。不能为了让方法完整，擅自把它解释成“作者只是针对特殊行业”。

## 产物三：表达 DNA

### E1：先给条件，再给建议

第一条先限定“探索一个新内容方向时”；第二条用需求与交付两个条件引出“可以增加投入”。这是两条材料中的共同组织方式。[source:sample_001] 正文第 1 段；[source:sample_002] 正文第 1 段。

**抽象模板：**

```text
当你处在[阶段]，先做[较小动作]。
观察到[信号]、同时具备[条件]之后，再考虑[下一步投入]。
```

**样本限制：** 只有两条支持这一表达观察；第三条直接使用绝对断言，没有相同条件结构。[source:sample_003] 正文第 1 段。不能据此宣称它是作者一贯的风格，也不能伪造跨时期精读结果。

## 最后应留下什么疑点

1. 低成本探索与“任何情况下先买齐设备”的冲突没有解释。
2. 需求稳定和交付稳定没有量化定义。
3. 这套投入建议没有效果数据，不能标为经过验证的方法。
4. 三条材料不足以概括一个人的完整思想或稳定表达风格。

这就是示例希望说明的工作方式：把素材支持的判断整理出来，同时保留它尚不能回答的部分。真实项目会有更多来源和卡片，证据要求相同。
