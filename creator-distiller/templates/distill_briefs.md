# 三件套模板

读取范围内所有可用总结，再回查支持关键结论的原文。素材过长可分批，保留覆盖记录。三份产物可以顺序完成；并行时避免共写文件，最后统一核对交叉引用。

共同要求：每张卡片或每条表达规律附 `[source:ID]` 及原文定位；区别作者观点、归纳、待验证推导；记录支持与反证。来源少则降低概括强度，不通过固定数量扩写。重复出现不等于因果有效。

## distilled/01_concepts.md：概念体系

- 概念地图：按材料本身的领域与关系组织。
- C1、C2…卡片：定义 / 解决的问题 / 判断逻辑 / 适用条件 / 边界与反例 / 对应方法编号 / 来源定位。
- 速查：用户问题 → 概念 → 下一步动作。
- 冲突与待验证事项。

## distilled/02_methods.md：方法论地图

- 按实际场景组织方法。
- M1、M2…卡片：目标 / 输入 / 步骤 / 输出 / 可观察验收 / 失败信号 / 条件与边界 / 来源定位。
- 原文未给验收指标时，写明“建议指标，尚未验证”，不要伪装为作者方案。
- 给出概念与方法的双向映射。用户需要落地时，选贴合用户目标的最小试运行；背景未知先列必须输入。
- 冲突与待验证事项。

## distilled/03_expression.md：表达 DNA

- 记录精读样本 ID、时期/题材分布、覆盖限制。
- 提炼跨样本结构、开场方式、句式、节奏、术语使用和反例；每条规律有来源。
- 将可迁移表达写成填空结构，不把特色口头禅或原案例当模板。
- 用户要求示例时另写原创短例，主题与受众取当前任务，标注“新写示例”。不默认加入两篇教育营销范文。
- 原创性审查考虑独特表述、情节和案例组合；连续六字重合不是可靠的独创性或版权判定标准。
