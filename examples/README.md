真实博主名称、94 条作品、85 页报告、设备转录耗时等历史数字，对新用户理解方法没有必要，而且无法在这个包内重现。这里改为 3 条新写的虚构素材，不附真实语料。

它只演示关键差异：

- `sample_001` 提倡探索阶段低成本尝试。
- `sample_002` 面向稳定需求和执行流程，建议适度增加投入；与前一条条件不同，可以并列说明，但不能声称已经实证有效。
- `sample_003` 用“任何情况下”作出相反判断，且没有解释。应保留冲突并列入待验证，不能替作者补出适用条件来消解矛盾。

> **C1：投入随证据调整。** 第一条建议探索期先观察反馈，第二条主张有稳定需求后扩大投入。[source:sample_001] 第 1 段；[source:sample_002] 第 1 段。第三条的绝对判断与此存在冲突，无法仅凭材料调和。[source:sample_003] 第 1 段。此卡片为假设性整理，未证明方法有效。
