# 示例：从一组观点到知识结构

以下基于三条虚构材料，只展示共脑的整理方式，不代表真实研究结论、法律或医学建议，也不是 Agent 实测成绩。

## 原始输入

- [sample_001](mini-archive/raw/sample_001.txt)：在限定环境和样本中观察到 X 与 Y 同时变化，但没有排除 Z。
- [sample_002](mini-archive/raw/sample_002.txt)：判断因果前要明确变量、检查替代解释和研究方法的支持程度。
- [sample_003](mini-archive/raw/sample_003.txt)：无新证据却主张同时变化必然构成因果，并适用于任何环境。

## 单条总结示意

第二条提出的是判断框架，而不是完整实验方案：明确变量 → 检查其他解释 → 评估研究方法支持何种结论。原文没有操作细节和阈值，不能补成验证过的流程。[source:sample_002] 正文第 1 段。

## C1：观察与解释的区分

这是分析者的归纳名称。第一条把观察范围和解释限制分开；第二条提出评估解释的条件。适用边界仅限当前材料能够支持的表述。[source:sample_001]、[source:sample_002] 正文第 1 段。

第三条的绝对判断与前两条冲突，原文没有说明原因。保留冲突，不能替讲述者添加条件来统一立场。[source:sample_003] 正文第 1 段。

## M1：检查一个解释依赖哪些条件

- 输入：原文中的变量定义、观察条件、替代解释及研究方法。
- 判断框架：区分观察与因果解释，记录原文是否处理替代解释，标明结论实际适用范围。
- 输出：一份前提、依据与缺口清单。
- 限制：这是对第二条的整理，不是可直接执行的实验方案；未提供的程序与指标应保持缺失。[source:sample_002] 正文第 1 段。
- 建议检查：每项解释能否对应到依据与条件。此检查由分析者提出，未声称经过效果验证。

## E1：通过限制条件界定论证

第一条先限定样本和环境，再表达不确定性；第二条列出判断前提。这是两条材料中可见的组织方式，不能凭这么小的样本概括其稳定风格。第三条使用绝对断言，是相反的表达例子。[source:sample_001]、[source:sample_002]、[source:sample_003] 正文第 1 段。

## 领域如何改变分析

同样是“某人解释某个问题”，处理法律内容时要保留地区、时间和规范依据；医学内容要保留人群和证据类型；工程内容要保留版本、单位和运行条件；人文内容要区分价值立场和经验事实。这些是取证要求，不是把所有行业套成一个结论。

## 同一底库怎样形成三种能力

下面继续使用以上虚构材料，展示预期交付逻辑；这是写好的教学示意，不是一次真实 Agent 试运行记录，也不能代替完整底库。

首次需求已说明来源为这三条材料、主题是论证判断；问询只需确定用途。若选思维方式和表达型，就生成两个包，完整三类知识仍保留；若只选持续服务者，就只生成服务包。

### 思考型：用概念分析新问题

用户输入：“活动以后咨询量增加，我能判断是活动造成的吗？”

生成的入口应引导 Agent 读取 C1、M1 及冲突记录，区分用户提供的前后观察与其因果解释，检查是否有替代解释、变量定义及方法依据。不能仅复述原文，也不能拿第三条绝对断言当普遍原则。可输出“目前给定事实不足以排除其他解释；需要补足哪些信息”。此处是把框架用于新问题的推导，不是原作者讨论过这个活动。

### 表达型：用用户事实组织新内容

用户输入：“我要向同事说明活动后咨询量增加，但还不能确定原因。”

参考 E1，把用户事实组织为限定范围 → 观察 → 解释限制 → 下一步核实。例如：“本次活动后，我们观察到咨询量增加。目前还不能区分活动和其他变化分别起了多大作用，需要结合活动期间的其他情况继续判断。”这是新写示例，不凭空增加数字，不照搬原作者经历，也不能声称经过真实业务检验。

### 持续服务者：形成论证检查助手

ROLE 定义为“依据这批材料辅助检查主张、证据和适用范围的助手”；不宣称具备完整科研或统计专业能力。SERVICE 先了解用户主张及证据，再给出前提、替代解释与缺口；用户补充材料后重新判断。

START 告诉用户将完整服务包和私人工作目录提供给所用 Agent。profile 保存用户已说明的任务目标；state 保存当前主张、已有依据、尚缺信息和下次切入点；history 保存实际输入、判断及后续反馈。未收到结果就记录“待反馈”，不能自动填入成功结论。

## 示例的意义与限制

这个小例子只展示：来源矛盾如何保留、纯判断框架怎样迁移、三种用途如何使用同一底库。真实材料的逐条详解仍须保留全部实质信息；真实生成包还应携带详细资料、来源和试运行记录，不以本页短示意代替。
