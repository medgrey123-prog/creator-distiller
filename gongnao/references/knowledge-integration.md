# 知识库集成与资料更新

## 生成能力包所需资料

按 [能力交付](capability-delivery.md) 将选中能力所需的详细资料存入包内 `knowledge/`，这是已选交付的组成部分，无需再问是否允许生成这些本地文件。完整主底库保持独立，不因包的用途而删去其他知识。

保留来源、卡片编号、版本和依赖关系；同一作品的音频、转录、详解不算三份独立证据。后续补做其他能力从主底库出发。输入变化后检查所有引用该资料的包，不能只更新一个包却声称全体系同步。

## 已有外部知识库

不绑定 Obsidian、某个人目录或专家编号。用户要求集成时先读目标库格式与规则，复用已有授权。

- 保留原始材料与来源映射；修改已有结论保留前后值、依据与冲突。
- 采集完成、归纳完成、引用存在、结论有效和用户接受分别记录。
- 候选区或审核流程按目标库规则执行，不强加额外审批。
- 没有外部写入授权时先交付可审查的导入文件；已获授权则执行并回读验证。
- 私人服务状态与公共知识分开放置；公共 Skill 更新不能清空或外传用户记录。
